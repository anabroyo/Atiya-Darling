# For Atiya ♡

A Taylor-Swift-meets-Y2K friendship website made for GitHub Pages.

## Upload to GitHub

1. Create a new repository on GitHub. You can name it something like `for-atiya`.
2. Upload **everything inside this folder**:
   - `index.html`
   - `style.css`
   - `script.js`
   - the entire `assets` folder
3. In your repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch (usually `main`) and the `/ (root)` folder.
6. Save. GitHub will generate your public website link after a short wait.

## Music note

The website uses the official YouTube embed for Taylor Swift's “Love Story”.
The music starts with full volume when the visitor presses **open your letter**, because browsers normally block sound before a user interaction.

Some browsers, privacy extensions, school/work networks, or countries can block YouTube embeds. If that happens, the rest of the website still works normally.
